# Artifacts API

> Source: `backend/app/gateway/routers/artifacts.py`
> Prefix: `/api`

Serve artifact files generated by the agent during a run. Handles MIME type detection, active content protection (HTML/SVG always forced to download), and transparent reading from inside `.skill` ZIP archives.

## Quick Reference

| Method | Path | Description | Access |
|--------|------|-------------|--------|
| `GET` | `/api/threads/{thread_id}/artifacts/{path}` | Retrieve an artifact file | `AUTH+OWNER` |

---

## Endpoint Details

### `GET /api/threads/{thread_id}/artifacts/{path}`

Retrieve an artifact file at the given virtual path. The path is resolved from the agent's virtual filesystem (`mnt/user-data/...`) to the actual host filesystem.

**Security note:** Active content types (`text/html`, `application/xhtml+xml`, `image/svg+xml`) are **always** served as attachment downloads to prevent script execution in the application origin. The `download` query param forces attachment behavior for all other types too.

**`.skill` archive support:** Paths of the form `mnt/user-data/outputs/my-skill.skill/SKILL.md` are transparently extracted from inside the ZIP archive (with a 16 MB per-member size cap; cached for 5 minutes to avoid re-extracting on every request).

**Access:** `AUTH+OWNER`

**Path Params:**

| Param | Description |
|-------|-------------|
| `thread_id` | Thread UUID |
| `path` | Virtual artifact path (e.g., `mnt/user-data/outputs/report.pdf`) |

**Query Params:**

| Param | Type | Default | Description |
|-------|------|---------|-------------|
| `download` | boolean | `false` | If `true`, forces `Content-Disposition: attachment` for all non-active content types (active content is always forced to download regardless) |

**Request Body:** None

**Response Behavior by Content Type:**

| Content Type | `download=false` | `download=true` |
|-------------|-----------------|-----------------|
| `text/html`, `application/xhtml+xml`, `image/svg+xml` | Attachment (forced download) | Attachment (forced download) |
| Other text types (e.g., `text/plain`, `text/markdown`) | Inline plain text | Attachment |
| Binary (e.g., `image/png`, `application/pdf`) | Inline with `Content-Disposition: inline` | Attachment |
| Unknown type (detected as text by content) | Inline plain text | Attachment |

**Responses:**

| Status | Description |
|--------|-------------|
| `200` | File content with appropriate content type and disposition |
| `400` | Path is invalid or not a file |
| `401` | Not authenticated |
| `403` | Path traversal detected |
| `404` | Artifact not found |
| `413` | `.skill` archive member exceeds 16 MB size cap |

**Example URLs:**

```
# View a text file inline
GET /api/threads/abc/artifacts/mnt/user-data/outputs/notes.txt

# Download a CSV file
GET /api/threads/abc/artifacts/mnt/user-data/outputs/data.csv?download=true

# Read SKILL.md from inside a .skill archive
GET /api/threads/abc/artifacts/mnt/user-data/outputs/my-skill.skill/SKILL.md
```
